📐 Справочник формул системной динамики ДТС

1. Целевая функция эффективности (Критерий минимизации потерь)
$$Z(p) = \int_{t_0}^{t_N} \sum_{i=1}^{n} \gamma_i \left(X_i^* - X_i(t, p)\right)^2 dt \to \min$$

Описание: Оценивает интегральное отклонение текущих показателей безопасности $X_i(t)$ от их рекомендованных оптимальных значений $X_i^*$ с учетом весовых коэффициентов $\gamma_i$[cite: 1].

Где используется: Вкладка «5. Выбор плана», формулы оптимизации выбора лучшего плана мероприятий $p(t)$[cite: 1].

2. Система дифференциальных уравнений системной динамики
$$\frac{dX_i}{dt} = \frac{1}{X_i^{norm}} \left( \prod_{j} f_{i,j}(X_j^+) \sum_{m} E_m^+ - \prod_{k} f_{i,k}(X_k^-) \sum_{n} E_n^- \right)$$

Описание: Описывает скорость изменения каждого показателя безопасности во времени как баланс между положительными (рост) и отрицательными (снижение) причинно-следственными темпами с учетом внешних факторов $E_m$[cite: 1].

Где используется: Численный решатель Рунге–Кутты 4-го порядка (RK4) для построения кривых прогноза на вкладке «1. Прогноз»[cite: 1].

3. Нормирование показателей безопасности
$$X_i^*(t) = \frac{X_i(t)}{X_i^{norm}}, \quad i = 1, \dots, 17$$

Описание: Перевод абсолютных статистических значений характеристик аварийности в безразмерную шкалу $(0; 1]$ для удобства сопоставления и расчетов[cite: 1].

Где используется: На входных параметрах модели и при проверке ограничений на лепестковых диаграммах[cite: 1].

4. Логистическая функция износа транспортных средств $E_2(t)$
$$E_2(t) = \frac{k_2^2 e^t}{k_2 + k_2(e^t - 1)}$$

Описание: Нелинейное внешнее возмущение среды, характеризующее накопление износа автопарка мегаполиса со временем[cite: 1].

Где используется: В правых частях дифференциальных уравнений (6) и (9) для переменных $X_1, X_2, X_4, X_5, X_8, X_{12}, X_{13}$[cite: 1].

5. Внутренние регрессионные зависимости (полиномы 2-й степени)
$$f_{A,B}(X_B) = a X_B^2 + b X_B + c$$

Описание: Характеризуют силу нелинейной причинно-следственной связи между причиной ($X_B$) и следствием ($X_A$), подобранные по статистике ГИБДД[cite: 1].

Где используется: Вкладка «3. Зависимости f(X)» и система уравнений (9)[cite: 1].
